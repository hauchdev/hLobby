# Security policy

## Supported versions

Only the latest release of hLobby receives security updates.

| Version | Supported |
| --- | --- |
| latest | yes |
| older | no |

## Reporting a vulnerability

If you discover a security vulnerability, please send a private email to
[hauch8bingo@proton.me](mailto:hauch8bingo@proton.me) instead of opening a
public issue. We will investigate and respond as soon as possible.

Please include as much detail as possible, such as:

- The hLobby and Velocity versions affected.
- Steps to reproduce the issue.
- Any relevant configuration or logs.
