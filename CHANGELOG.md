# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Initial release of hLobby.
- Six lobby selection strategies: random, least players, most players, first
  available, priority and round-robin.
- Configurable teleport countdown with command/chat cancellation.
- Per-player `/lobby` cooldown.
- Join and kick redirection to lobbies.
- Administrative commands to create, remove, list, transport, teleport and
  configure lobbies.
- English and Spanish translations using MiniMessage.
- Server statistics cache refreshed periodically.
- Optional bStats metrics integration.
- GitHub update checker.
- Small public API for third-party plugins.
- Unit tests for selectors, teleport modes and version comparison.

### Changed

- Migrated from the Devix scaffold to a full-featured Velocity plugin.
